# AWS Console Home
  The AWS Management Console is the website where you can create, manage, and monitor AWS services
## Search bar:
  EC2, 
  S3,
  RDS,
  IAM,
  VPC
## Region:
   At the top right, you can select an AWS region are
   Asia Pacific (Mumbai) – ap-south-1
   Asia Pacific (Hyderabad) – ap-south-2
## Recently visited :
   Shows services you opened recently.
## Services:
   You can browse all available AWS services.
## Account information :
   your account/profile menu is at the top right.
## Billing and Cost management:
   you can check your AWS charges and usages. These is especially important when your learning AWS
## what is IAM (Identity and Access management)?
   IAM is an AWS service used to control who can access AWS resources and what they are allowed to do.
## what is EC2 (Elastic Compute Cloud) :
   EC2 gives you a virtual server/computer in the AWS cloud.
## what is S3 (Simple Storage service):
   S3 is used to store the files and objects in the cloud.
## For example :
   Images,
   Videos,
   PDFs,
   Documents,
   Backups,
   Application files
   
## S3 stores these files inside something called a bucket.
